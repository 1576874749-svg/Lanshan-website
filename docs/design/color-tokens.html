蓝山工作室 · 统一配色方案

基于 TDesign 语义 Token 体系，将现有 styles.css 中的 14 个 CSS 变量 + 20+ 处硬编码颜色 重组为 Brand（品牌）、Surface（表面）、Text&Border（文字边框）、Status（状态）四层。每个 Token 均注明暗/亮双色值。

设计体系：TDesign Semantic Token Core Token：14 个 新增 Token：6 个 主题：亮色 / 暗色

第一层 Brand 品牌色

品牌核心三色：蓝色（主色）、薄荷（辅助）、暖橙（强调）。每个色提供 Light / Dark 两种场景值。

品牌色使用准则：主按钮用 --brand-primary（蓝），辅助标签/装饰用 --brand-secondary（薄荷），强调/警示用 --brand-accent（暖橙）。三类不互换使用。

映射 硬编码颜色 → Token 合并方案

当前 styles.css 中仍有 ~20 处硬编码颜色未挂载到 CSS 变量。建议新增 6 个 Token 统一收口。

新增 Hero 渐变 Token

  • rgba(95,148,218,.2) / rgba(0,205,255,.2)→--hero-glow
  • #fbfdff→#edf4ff→#effaf8→--hero-bg-light
  • #020711→#061227→#03101d→--hero-bg-dark
  • rgba(247,250,255,.94)→transparent→--hero-mask-light
  • #9bb2cf/#7794b9/#a9bdd5...→--hero-muted

新增 项目卡片 Token

  • #142957→#5169a8→--feature-gradient
  • #b9caf5 / #c5d2e9→--feature-text
  • #9eafd0→--feature-muted
  • #87d5bd (pulse dot)→复用 --mint-bright

新增 加入我们 Token

  • #e4edff→#dff8ef→--join-gradient-light
  • #13274d→#143d3d→--join-gradient-dark
