# 蓝山工作室官网交互原型

纯前端高保真交互原型，围绕蓝山工作室的品牌、部门、项目、毕业去向与招新信息进行展示。

## 主要体验

- 星空背景与蓝山 Logo 3D 粒子山
- 点击粒子山后炸开并自动重组
- 桌面端三级部门拓扑、手机端树状列表
- “关于蓝山”品牌页面
- 项目背景、解决方案、成果数据与参与部门案例结构
- 中国地图毕业去向与匿名校友数据
- 新版社交页脚与微信、小红书、哔哩哔哩入口
- 详细中国地图、浏览器兼容的粒子山路径测量

## 设计实验入口

- `index-tdesign.html`：TDesign / Vue 组件实验页
- `prototype-blueprint.html`：页面结构与交互蓝图
- `color-tokens.html`：色彩与设计令牌参考

实验页不会替换主入口 `index.html`，便于团队继续比较不同设计方案。

## 本地构建

```bash
npm run build
```

构建产物输出至 `dist/`。网站的核心页面为纯静态文件，也可以直接通过 GitHub Pages 发布。

## 原型边界

- 招新群二维码、邮箱、地址和成员信息仍为占位内容。
- 首页「近期动态」为占位示例数据（`data/site-data.json` 的 `news` 字段），正式上线前需替换为真实动态。
- 毕业去向暂时使用匿名示例数据。
- 蓝妹 3D 形象暂不实现。
- 动画尊重系统的“减少动态效果”设置。
