# 蓝山工作室官网交互原型

纯前端高保真交互原型，围绕蓝山工作室的品牌、部门、项目、毕业去向与招新信息进行展示。

## 主要体验

- 星空背景与蓝山 Logo 3D 粒子山
- 点击粒子山后炸开并自动重组
- 桌面端三级部门拓扑、手机端树状列表
- “关于蓝山”品牌页面
- 项目背景、解决方案、成果数据与参与部门案例结构
- 中国地图毕业去向与匿名校友数据

## 本地构建

```bash
npm run build
```

构建产物输出至 `dist/`。网站的核心页面为纯静态文件，也可以直接通过 GitHub Pages 发布。

## 原型边界

- 招新群二维码、邮箱、地址和成员信息仍为占位内容。
- 毕业去向暂时使用匿名示例数据。
- 蓝妹 3D 形象暂不实现。
- 动画尊重系统的“减少动态效果”设置。
